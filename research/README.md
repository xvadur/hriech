# Výskum Hriechu

Toto je kanonický vstup do mediálnej kritiky.

- `newsrooms/` — verejné podklady k organizačnej mape médií.
- `editorial/` — investigatívne a produktové briefy.

Interné case files a sourcebooky sú v lokálnom ignorovanom
`../private/research/`; raw zdroje sú v ďalších podadresároch `../private/`.
Verejný text musí odkazovať na publikovateľný primárny zdroj, nie na existenciu
súkromného prepisu.
